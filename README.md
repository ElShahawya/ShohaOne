# SHAHA ONE | شها ون — دليل ومركز خدمات قرية شها

منصة مجتمعية ورقمية متكاملة تخدم أهالي **قرية شها — مركز المنصورة — محافظة الدقهلية**. تجمع المنصة كافة أرقام الطوارئ، الأطباء، الصيدليات، المعلمين، الحرفيين، المتاجر، بنك الدم، الحالات الإنسانية، وأخبار القرية، مع لوحة تحكم إدارية ونظام ملفات شخصية متطور.

---

## 🌟 الميزات الرئيسية (Core Features)

1. **دليل الأرقام والخدمات (Comprehensive Directory)**:
   - تصنيف دقيق للأنشطة والمهن (أطباء، صيدليات، معلمين، محلات، حرفيين، خدمات حكومية).
   - صفحات شخصية تفاعلية تدعم رفع وتعديل صور الغلاف والشعار بضغط تلقائي فائق الكفاءة.
   - دعم شامل لـ 9 منصات تواصل اجتماعي (فيسبوك، واتساب، انستجرام، تيليجرام، تيك توك، يوتيوب، لينكد إن، الموقع، روابط مخصصة).
   - نظام المفضلة، بطاقات QR، التقييمات، والإبلاغ عن بيانات غير صحيحة.

2. **بنك الدم والطوارئ الطبية (Blood Bank & Emergency Hub)**:
   - سجل متبرعي الدم الطوعي مع فلترة الفصائل وإخفاء الهوية عند الطلب.
   - نداءات التبرع بالدم العاجلة مع ربط مباشر بمستشفيات المنصورة.
   - جدول استقبال طوارئ مستشفيات المنصورة الأسبوعي مع ميزة الطباعة والمشاركة.

3. **التكافل والمساعدات الإنسانية (Mutual Aid & Charities)**:
   - الحالات والعمليات الطارئة مع تتبع مبالغ التبرع المجمعة.
   - دليل الجمعيات الخيرية والمبادرات التنموية بقرية شها.

4. **لوحة التحكم والإدارة (Admin & Governance)**:
   - مصادقة مزدوجة (حساب Google المعتمد + كلمة مرور المشرف المحمية بتشفير PBKDF2).
   - إدارة كاملة للخدمات، الأقسام، طلبات الإضافة، البلاغات، وبطاقات التوثيق.
   - سجل تدقيق إداري (Audit Trail) لجميع العمليات الحساسة.

5. **المتانة والأمان (Zero-Downtime Resilience)**:
   - استراتيجية الحفظ المزدوج (Dual-Write Persistence) بين Firebase Firestore والخادم المحلي.
   - حماية PII وتشفير البيانات الحساسة عبر معيار AES-256-GCM.
   - ضغط صور الغلاف (<120KB) والشخصية (<65KB) داخل المتصفح لتوفير مساحة التخزين.

## 🚀 التشغيل المحلي (Local Development)

### المتطلبات
- **Node.js**: الإصدار 20 أو 22 LTS
- **npm**: الإصدار 10 أو أحدث

### خطوات التثبيت والتشغيل
```bash
# 1. استنساخ المشروع
git clone https://github.com/your-repo/shaha-directory.git
cd shaha-directory

# 2. تثبيت الحزم
npm install

# 3. إعداد المتغيرات البيئية
cp .env.example .env

# 4. تشغيل خادم التطوير
npm run dev
```

التطبيق سيعمل مباشرة على: `http://localhost:3000`

## 📦 أوامر البناء والتشغيل (Scripts)

| الأمر | الوصف |
| :--- | :--- |
| `npm run dev` | تشغيل خادم التطوير المتكامل (Express + Vite HMR) على المنفذ 3000 |
| `npm run build` | بناء نسخة الإنتاج للعميل (Vite) وتجميع الخادم (esbuild) داخل مجلد `dist` |
| `npm run start` | تشغيل خادم الإنتاج المجمع `node dist/server.js` |
| `npm run lint` | التحقق الصارم من صحة الأنواع وشفرة TypeScript عبر `tsc --noEmit` |
| `npm run preview` | معاينة حزمة الويب المنتجة محلياً |
| `npm run backup` | أخذ نسخة احتياطية فورية لبيانات النظام وسجلات التدقيق وقواعد الأمان |
| `npm run backup:verify` | التحقق من صحة النسخ الاحتياطية وتطابق توقيعات SHA-256 |

## 🌐 خيارات النشر العالمي (Universal Deployment)

المنصة مصممة ومجهزة بالكامل للعمل على مختلف بيئات الاستضافة:

1. **Docker / Cloud Run / VPS**:
   - يوجد `Dockerfile` متعدد المراحل عالي الأمان يعمل بمستخدم غير جذري (non-root).
2. **Firebase Hosting**:
   - إعداد كامل عبر `firebase.json` مع توجيهات الـ SPA وترويسات الأمان.
3. **Vercel**:
   - إعداد فوري عبر `vercel.json`.
4. **Netlify**:
   - إعداد مسبق عبر `netlify.toml` و `public/_redirects`.
5. **Cloudflare Pages**:
   - دعم مباشر عبر `public/_routes.json` و `public/_headers`.

راجع دليل النشر التفصيلي في [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md).

## 🔒 الأمان وحماية البيانات (Security)

- **قواعد Firestore الصارمة (`firestore.rules`)**: تطبيق مبدأ الصلاحيات الأدنى (Least Privilege) ومنع الكتابات العشوائية.
- **تشفير البيانات الحساسة (AES-256-GCM)**: حماية السجلات الخاصة وأرقام الهواتف الحساسة بمحرك التشفير القياسي في `src/lib/encryption.ts`.
- **حماية تسجيل الدخول**: قفل تلقائي لمدة 15 دقيقة بعد 5 محاولات خاطئة لمنع هجمات التخمين (Brute-force).
- **ترويسات الحماية**: تفعيل `Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, وسياسات الأذونات.

للمزيد، راجع [SECURITY.md](./SECURITY.md) و [FIREBASE_SECURITY.md](./FIREBASE_SECURITY.md).
